# Pigverse Glossary

**Application Admin** — Authorized operational user who signs a wallet challenge to access the Admin Dashboard. Separate logical role from Contract Owner.

**Available** — Publicly published Genesis NFT that is not yet minted and can be minted if contract/network conditions permit.

**Base Mainnet** — Planned production blockchain network for the production Pigverse deployment.

**Base Sepolia** — Blockchain test network used for Pigverse development/testing.

**Backup Storage** — Secondary durable storage used in addition to IPFS for artwork/metadata recovery.

**Blockchain Source of Truth** — Rule that current NFT mint existence and ownership are determined by the deployed contract state, not by the application database.

**Collector** — User who connects an EVM wallet to mint or view owned Pigverse NFTs.

**Contract Owner** — Single wallet authorized by the smart contract to perform owner-only actions such as pause/unpause and mint-price changes.

**DRAFT** — NFT content state in which Admin may edit character data before asset processing/publication.

**ERROR** — Asset/content processing state indicating a required step failed; NFT cannot be published until resolved.

**Genesis / Pigverse Genesis** — First Pigverse collection containing exactly 10 unique 1/1 NFTs with token IDs 1–10.

**IPFS** — Content-addressed decentralized file system used for NFT artwork and metadata persistence.

**Lore / Story** — Character narrative content available in Vietnamese and English.

**MINTED** — On-chain state in which a Genesis token ID has been successfully created/assigned and has a current owner.

**MINT_PENDING** — Temporary UI state after transaction submission but before final successful/failed on-chain resolution. It is not ownership.

**Mint Price** — Contract-enforced amount required to mint a token. Base Sepolia starts at zero; production price is TBD.

**My NFTs** — Page showing Genesis tokens currently owned by the connected wallet.

**NFT** — Non-fungible token representing one Pigverse character token on-chain.

**No Commercial Rights** — Current license model: holder may own the NFT and use artwork personally/socially, but does not receive copyright or commercial exploitation rights.

**Oink Crystal** — Narrative object at the center of the current proposed/accepted Pigverse lore concept connecting the 10 characters.

**Pigverse** — Product/universe name.

**PUBLISHED / AVAILABLE** — NFT content is publicly visible and eligible to mint if contract state also permits.

**READY** — Asset processing completed successfully and NFT may be published by an Admin.

**Season 2 / Collection 2** — Future separate Pigverse collection that must not change Genesis token IDs, max supply or mint history.

**Token ID** — Fixed numeric identifier for Genesis NFT, 1 through 10.

**1/1** — Unique NFT representation: the specific token/artwork exists as one token, not an edition with multiple copies.
